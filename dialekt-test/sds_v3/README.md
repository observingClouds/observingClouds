Unmodified copy of the digitized *Sprachatlas der deutschen Schweiz* (SDS) maps, version 3, from
<https://dialektkarten.ch/static/geojson/swg_v3/> (Y. Scherrer, S. Kellerhals, R. Weiss).
The copy is mirrored here because GitHub serves files with CORS headers, which lets the notebook run in the browser on marimo.app.
